BETA RELEASE

1. 개요

Resize Image Manager는 마야(Maya) 환경 내 텍스처 리사이즈 공정을 자동화하기 위한 외부 독립 유틸리티입니다. 포토샵 등을 이용한 수동 리사이즈의 번거로움을 해결하고, 마야 셰이더 데이터를 직접 참조하여 지정된 해상도로 이미지를 일괄 재생성합니다.

현재 배포된 버전은 파이프라인 도입 검토를 위한 베타(Beta) 단계이며, 핵심 리사이즈 엔진의 안정성을 우선적으로 테스트합니다.

2. 설치 및 디렉토리 구조

본 프로그램은 무설치 포터블(Portable) 방식으로 동작하며, 배포된 폴더 내의 실행 파일을 직접 실행하시면 됩니다.

2.1 파일 구성

resizeImgManager/
 ├── _prev.json           // UI 마지막 설정 상태 보존
 ├── _shaderData.json     // 마야로부터 수신한 셰이더 원본 데이터
 └── resizeImgManager.exe // 메인 바이너리 실행 파일
데이터 보존 주의: 상기 .json 파일들은 툴 종료 시 현재 설정값을 기억하기 위해 자동으로 업데이트됩니다. 현재 베타 버전이므로 세팅 유지를 위해 가급적 파일을 삭제하지 마십시오. (삭제 시 모든 설정이 초기화됩니다.)

3. 마야 소켓 통신 설정 (최초 1회 필수)

툴이 마야의 데이터를 읽어오려면 두 프로그램 간의 통신 연결이 필요합니다. 최초 1회 아래 순서대로 세팅을 진행해 주시기 바랍니다.

  1. 설치 파일 생성 및 마야(Maya) 화면에 드래그 앤 드롭:
    - 먼저 툴 화면 상단의 [make connect code] 버튼을 클릭합니다.
    - 윈도우 탐색기 폴더가 자동으로 열리며, 파란색으로 선택된 dragMayaViewPort.py 파일이 나타납니다.
    - 이 파일을 마우스로 클릭한 채 쭉 끌어서(Drag) 마야(Maya)의 3D 작업 화면(Viewport) 한가운데에 놓아줍니다(Drop).
    - 정상적으로 적용되면, 마야 상단의 쉘프(Shelf) 탭에 붉은색 글씨로 'resize'라고 적힌 파이썬 모양의 버튼이 새로 생성됩니다.
  2. 마야 통신 서버 열기:
    - 마야의 쉘프(Shelf)에 방금 생성된 붉은색 'resize' 아이콘을 클릭합니다.
    - 클릭하면 마야 우측 하단의 짧은 로그 줄(또는 스크립트 에디터)에 >> [resizeManager] 포트 열림: localhost:7772 와 같은 메시지가 표시됩니다. (버튼을 한 번 더 누르면 포트가 닫힙니다.)
  3. 툴과 최종 연결하기:
    - 다시 Resize Image Manager 툴 화면으로 돌아와서 [connect] 버튼을 누릅니다.
    - 버튼 옆의 숫자(포트) 입력칸이 파란색(🟦)으로 변하면 완벽하게 연결된 것입니다! (만약 붉은색(🟥)으로 변한다면 마야에서 resize 아이콘을 다시 눌러주세요.)

4. 리사이즈 워크플로우

4.1 텍스처 데이터 불러오기

마야에서 작업할 오브젝트를 선택하고, 툴 중앙의 [shader type](예: RedshiftMaterial)을 지정한 뒤 우측의 새로고침(🔄) 아이콘을 클릭하면 리스트가 나타납니다.

// 테이블 출력 예시
[Object_A] | [RedshiftMaterial1] | [C:/Project/sourceimages/tex_dif.jpg]
[Object_B] | [RedshiftMaterial2] | [None] // 텍스처가 없는 경우

※ 참고: 마야에서 텍스처가 제대로 연결되지 않은 오브젝트는 위 예시처럼 테이블에 None으로 표시됩니다. None으로 표시된 항목들은 실행(Build) 시 툴에서 알아서 무시하고 넘어가므로 리스트에서 굳이 삭제하지 않고 그대로 진행하셔도 안전합니다.

4.2 리사이즈 실행 (Build)

  • 대상 선택: 테이블에서 리사이즈할 항목들을 마우스 드래그나 Shift 클릭으로 파랗게 선택합니다.
  • 저장 폴더 및 파일명 (folder path / save name):

    폴더(📂) 아이콘을 눌러 리사이즈된 이미지가 저장될 폴더를 지정하고, 규칙에 맞게 저장될 파일명을 설정합니다.

    ※ 필수 주의사항: 파일명 입력칸에는 반드시 {name}이라는 예약어가 포함되어야 합니다. {name}은 마야에서 추출한 '원본 텍스처 파일명'으로 자동 치환됩니다.

    💡 실제 빌드(저장) 예시:
    만약 마야 원본 텍스처 이름이 character_body_dif 이고,
    툴의 입력칸에 resize_{name}_v2.jpg 라고 설정 후 빌드했다면,
    최종적으로 resize_character_body_dif_v2.jpg 라는 이름으로 일괄 저장됩니다.

  • 크기 설정: 원하는 가로(Width)/세로(Height) 픽셀 사이즈를 입력합니다. (예: 512, 1024)
  • 맨 아래 [build] 버튼을 누르면 작업이 시작되며 프로그레스 바가 차오릅니다. `open folder` 옵션이 체크되어 있다면 작업 완료 후 해당 폴더가 자동으로 열립니다.

5. 기술 FAQ

Q. 마야 내부 스크립트가 아니라 왜 외부 프로그램(.exe)으로 만들어졌나요?

이 툴은 수십 장의 대용량 이미지를 순식간에 처리하기 위해 OpenCV라는 강력한 고성능 이미지 프로세싱 모듈을 사용합니다.

하지만 OpenCV는 마야나 일반 사용자 컴퓨터에 기본적으로 설치되어 있지 않습니다. 만약 이 툴을 일반적인 마야 스크립트로 배포했다면, 작업자분들이 직접 파이썬을 설치하고 복잡한 명령 프롬프트(cmd) 환경을 열어 `pip install opencv-python`을 일일이 타이핑하여 설치해야 하는 큰 불편함이 발생합니다.

이러한 번거로움을 원천적으로 차단하고, 더블클릭만으로 누구나 즉시 사용할 수 있도록 필요한 모든 모듈을 하나로 패키징하여 외부 프로그램 형태로 배포하게 되었습니다.

Q. 파일 패턴(file Pattern)은 어떻게 설정하나요?

파일 패턴은 마야에 연결된 수많은 텍스처(노말, 스펙큘러 등) 중에서 원하는 텍스처만 정확히 필터링하기 위한 검색 규칙입니다. 기본적으로 제공된 양식을 활용하여 쉽게 설정하실 수 있습니다.

- 권장 기본값: (.+)(_dif)(\.jpg) (디퓨즈 맵을 추출할 때 이 값을 유지해 주십시오.)
- 수정 방법: 현재 툴은 `.jpg` 포맷을 기준으로 작동합니다. 만약 다른 맵(예: 노말 맵, 스펙큘러 맵 등)을 추출하고 싶으시다면, 괄호나 특수 기호는 그대로 유지한 채 가운데의 _dif 텍스트만 _nrm 이나 _spec 등으로 변경하여 사용해 주시면 됩니다.

Q. 에러 발생 시 로그(Log) 창은 어떻게 보나요?

툴 우측 상단의 [ 🔼 모양의 창 띄우기 아이콘 ]을 클릭하면 작은 로그 창이 팝업창으로 분리/확장되어 상세한 작업 내역 및 에러 로그를 편하게 확인하실 수 있습니다. 옆의 휴지통 아이콘을 누르면 출력된 텍스트가 지워집니다.
